# demo-001 — учебный пример

Запрос для запуска: «Проанализируй проект demo-001 по материалам в inputs. Руководитель видит падение повторного использования и выбирает дальнейшее направление. Подготовь обоснованные продуктовую и коммуникационную стратегии и план проверки».

Решение: сохранить продукт, исправить активацию, развить регулярные задачи либо закрыть направление. Цель — выбрать следующий обратимый шаг с явной экономической границей; адресат — руководитель продукта. Приоритет прибыли/роста руководителем не утверждён: рабочее допущение — сначала избежать необоснованных инвестиций, сохранив возможность проверить ценность.

Это синтетический пакет разработки M1. Официальный отдельный бриф не получен. Публичная страница организатора подтверждает дедлайн 22 ноября 2026, 23:59 Europe/Moscow; соответствие финальному демонстрационному брифу не заявляется.

Разрешённые входы: файлы `inputs/` этого проекта и официальная публичная справка Todoist на `www.todoist.com`. Разрешено локальное извлечение/расчёты и чтение публичной страницы через уже доступный host. Нет разрешения на новые внешние сервисы, публикацию, контакт с клиентами, покупки или реальные продуктовые изменения.

Пишет только один координатор; outputs/evidence/state версионируются. Старые выводы не независимые источники. Коррекция данных в рамках приёмки будет явно отмечена как тестовая, без вымышленного бизнес-одобрения.
