# Официальные требования и доступ

Проверка 17 ноября 2026 года. [Публичный сайт](https://challenge.mgimo.ai/) и связанный [регламент](https://challenge.mgimo.ai/rules) доступны через веб-инструмент. Регламент: русский язык, подача капитаном через кабинет, срок 22 ноября 2026 года 23:59 МСК; уточнённые требования публикуются вместе с заданиями. Это не содержание дополнительного брифа.

[Страница кейса](https://challenge.mgimo.ai/cabinet/nominations/ai-project) не прочитана. Переход «Личный кабинет» ведёт на [вход](https://challenge.mgimo.ai/login); подключённых авторизованных сессий документов нет. Разрешённый прямой HTTPS завершился SSL EOF. Не делались попытки отключить TLS, извлечь учётные данные или обойти вход. Сверка проводится по предоставленному [тексту кейса](../../DescriptionMegafonAIAgent.txt); его актуальность относительно закрытого дополнения не утверждается.

Предназначенный [GitHub-адрес](https://github.com/AiratBastanov/MegafonAIAgent) и публичный API вернули 404. Это не различает закрытый и отсутствующий репозиторий. Локальный каталог не является Git checkout: `git status --short` вернул `fatal: not a git repository`. Состояние удалённых веток и права на публикацию не установлены.

[Первый сетевой отказ](external-access.json), [разрешённое чтение адресов](external-access-supported.json). Повтор с теми же условиями не выполнялся. Владелец не должен искать или переписывать бриф; для его проверки нужен доступ к уже авторизованной сессии кабинета.
