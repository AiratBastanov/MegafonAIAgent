# Локальный экспортёр и проверенный черновик

`export_pdf.py` использует уже доступные Markdown 3.9 и PyMuPDF 1.26.3. Установок, новых сервисов или изменений среды нет. Запуск из корня проекта:

```powershell
python -X utf8 evaluation/task07/editorial/export_pdf.py --source evaluation/task07/editorial/Описание-проекта-черновик-2.md --output evaluation/task07/editorial/Новое-имя.pdf --draft --png-dir evaluation/task07/editorial/Новая-папка-страниц
```

Для окончательного текста убрать `--draft`. Без этого флага экспортёр откажет, если в исходнике остались `РЕДАКТОРУ:` или `[[SCREENSHOT: ...]]`. Существующий PDF и изображения не перезаписываются: для нового экспорта нужно новое имя. Логические страницы разделяются `<!-- PAGE -->`; каждая начинает отдельную страницу. Переполнение сохраняется и показывается в отчёте, шрифт автоматически не уменьшается. При более чем пяти страницах возвращается ошибка для осмысленного пересмотра композиции.

Исходник версии 2 — отдельный файл. Критерий записан как три совместных условия: ≥5/6 завершений, медианное снижение времени ≥20%, ошибки не растут. Оригинал не изменён. Два места для кадров явно подписаны как черновые; рендер документов вместо кадров туда не вставлен.

Пробный файл [Описание проекта — проба](Описание-проекта-проба-1.pdf) содержит пять страниц; основной текст 11,25 pt, таблицы 9,7 pt. Пять логических разделов заняли по одной странице. Рядом находится машинный отчёт с SHA, версиями библиотек и ссылками. Все страницы прочитаны через реальные PNG из `preview-1/`.

Визуальная проверка:

1. Задача, исходное противоречие и три официальные альтернативы. Текст и таблица читаемы, последняя строка не упирается в нижнее поле.
2. Четыре варианта, условный выбор, сообщение и согласованные пороги. Заголовок, таблица и абзацы не разорваны; нет потерянного окончания.
3. Изменение экономики и место реального сопровождения. Сейчас страница намеренно неполная: окончательный абзац о фактическом симулированном выборе и читаемый кадр должны занять свободное пространство. Этот черновик не выдаётся за окончательную вёрстку.
4. Схема, память, продолжение и ключевые инструкции. Схема читаема, не обрезана; места под второй кадр достаточно только для узкого содержательного фрагмента окна. Полное окно 1440×900 при ширине страницы может вызвать перенос. Предпочтителен кадр результата/сохранения с сохранённым полным оригиналом; при невозможности оставить один кадр на странице 3, а подтверждение продолжения дать текстом и ссылкой.
5. Инструменты, частичное измерение ресурсов, честное сравнение, запуск и ограничения. Таблица и абзацы читаемы, служебных идентификаторов в видимом тексте нет.

Относительные PDF-ссылки преобразуются по расположению выходного PDF; проверяются существующие локальные цели. При переносе готового PDF отдельно от проекта нужно заново оценить доступность этих файлов. Окончательный PDF после фактических вставок требует нового просмотра всех страниц, кадров, ссылок и границ.
