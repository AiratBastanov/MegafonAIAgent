# Редакторские проверки

- Черновик описания: 1322 слова по счётчику кириллических/латинских/числовых токенов после удаления HTML-комментариев и целей ссылок. Все относительные ссылки в исходном расположении существуют. Число страниц определяется окончательной вёрсткой и изображениями.
- Первый SVG-рендер через PyMuPDF прочитан визуально: text-anchor, унаследованный от g, не применился, часть подписей вышла за границы. Исходный SVG и первый PNG сохранены. Минимальная коррекция: явный text-anchor и font-family на каждом text, отдельный выход с суффиксом «готово».
- Промежуточная однострочная Python-команда с экранированными двойными кавычками через PowerShell завершилась SyntaxError: unterminated string literal, exit 1; файлы не менялись. Попытка не повторялась: точный код перенесён в локальный render_diagram.py и вызван обычным Python, это коррекция синтаксиса оболочки, не обход политики.

Исходная ошибочная операция: Python -c читал SVG и пытался выполнить replace('<text ', '<text text-anchor="middle" font-family="Arial" '), затем рендер. PowerShell изменил кавычки строкового литерала. Для итогового воспроизведения использовать файл render_diagram.py.
