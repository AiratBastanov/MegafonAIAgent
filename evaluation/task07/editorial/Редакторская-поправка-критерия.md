# Поправка критерия проверки

Исходный «Описание-проекта-черновик.md» сохранён без изменения. В нём предложение «медианное снижение времени менее 20% без сокращения ошибок» неоднозначно связывает два условия и может допустить рост ошибок. Координатор уточнил итоговый критерий: не менее 5/6 успешных завершений, медианное снижение времени не менее 20%, ошибки не растут. Это предлагаемые пороги, не наблюдённые результаты.

В отдельной версии «Описание-проекта-черновик-2.md» условия записаны прямо и совместно; невыполнение любого не поддерживает переход к следующему этапу. Исходные исторические документы, файлы демонстрации и state редактором не менялись. Окончательные стратегии и план проверки должны использовать тот же смысл.

Средство экспорта: существующий Python 3.12, Markdown 3.9, PyMuPDF 1.26.3. Ожидаемая `.venv-export` в корне отсутствует; новых зависимостей не установлено. Это соответствует прежней записи `submission/export/requirements-export.txt`: библиотеки доступны системному Python и не нужны агенту для анализа.
