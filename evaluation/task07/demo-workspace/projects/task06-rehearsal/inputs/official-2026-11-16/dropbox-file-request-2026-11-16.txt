Версия локальной записи: 1. Это датированный пересказ и короткая цитата, не полный HTML и не испытание сервиса.

Вводный раздел, строки 55–63: запросы файлов доступны на всех планах; отправителю не нужен аккаунт Dropbox. Полученные материалы занимают место в аккаунте получателя; нехватка места приводит к ошибке загрузки.
Там же, строки 62–63: Basic/Plus/Family принимают файлы до 2 GB; Professional/Essentials/Business/Business Plus/Standard/Advanced/Enterprise — до 250 GB. Это размер входящего файла, а не лимит исходящей передачи Dropbox Transfer.
Раздел How to create a file request, строки 73–75: срок приёма и разрешение поздних загрузок описаны для Professional/Essentials/Business/Business Plus/Standard/Advanced/Enterprise. Пароль указан отдельным необязательным шагом без явного планового ограничения; не следует переносить ограничения пароля Transfer на file requests.
Строки 82 и 94: администратор команды может отключить запросы; папка назначения по умолчанию закрыта от других.
Раздел How to close a file request, строка 111: закрытие прекращает новые загрузки до повторного открытия.
Короткая цитата, строка 74: “Add a password (optional).”
Ограничение: не доказаны бухгалтерские интеграции, соответствие требованиям конкретного клиента, спрос или экономика RelayBox.
