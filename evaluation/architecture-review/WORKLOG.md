# Журнал архитектурного аудита

17 ноября 2026 года. Координатор — текущий Codex; три отдельных автоматических контекста проверяли код, поставку и содержание. Бизнес-состояния писал только исходный координатор демонстрации; во время аудита они не менялись. Публикация и отправка не выполнялись.

- Прочитаны реальные AGENTS, конкурсный кейс, README, актуальные отчёты и связанные доказательства. Git checkout отсутствует: `fatal: not a git repository`; для версии используются хеши файлов и ZIP. Шесть названных guidance-файлов не найдены. Глобальный AGENTS пуст, override отсутствует; конфигурации/учётные данные не читались.
- Независимо подтверждены CRC/SHA прежнего ZIP, 4381 запись manifest, исторические 85 тестов, offline установка, успешный независимый r1→r2 и отдельный load. Дата 17 ноября относится к due_at, не публикации. Даты исходных событий не менялись.
- Получены три воспроизводимых дефекта: stale draft, потеря synthetic и synthetic completion вне evaluation. Исходные байты сохранены в before, воспроизведения — в reviewer. Исправлены контракт исходной версии и наследование происхождения; reviewer исправил общий guard, координатор проверил diff. Новые компоненты не добавлялись.
- Независимая содержательная проверка подтвердила различие сценариев и согласованность текущих стратегий. Новый продуктовый сценарий не нужен. Для рутинного продолжения добавлена summary после полной валидации; измерено 158636→6557 UTF-8 байт, это не измерение токенов.
- Затронутые тесты и локальная регрессия прошли: 93 теста, 7,376 с внутри unittest; процесс 7,781 с. Время вложенного теста и процесса не складывается. Точные команды, UTC, stdout/stderr и хеши — `observations`. Неизвестные токены/стоимость этого аудита не оценивались.
- Исправлена неоднозначная Unicode-аннотация PDF. Первая попытка percent-encoding Filespec стала двойным кодированием в PyMuPDF; диагностирован raw /Launch. Выбран правильный PDF Unicode-string с BOM через get_pdf_str, /F и /UF. Экспорт v2 прошёл, все пять рендеров при масштабе 1,5 совпадают с прежним PDF. Содержание и видео менять не требуется. Первая попытка сохранена как диагностический артефакт, не итоговый PDF.
- Технические ошибки собственных диагностик: Get-Content без UTF8 показывал искажённый русский текст; последующие чтения явные UTF8. Предполагаемый `build_release.py` отсутствует, поиск показал `package.py`; wildcard в Windows rg заменён поиском по каталогу. PowerShell stdin без OutputEncoding потерял кириллицу и дал `OSError [Errno 22] ... ?????`; чтение выполнено после явной UTF8-кодировки. System Python имеет fitz, но не pypdf (`ModuleNotFoundError`); независимый PDF-парсер запускается уже установленной .venv, без новых установок и изменения окружения. Один исходный patch reviewer был отвергнут пустым hunk; исправленный применён. Ошибки не объявлялись дефектами продуктовых данных.
- Архитектурная карта переписана по фактическому коду; прежние документы сохранены с суффиксом .txt, чтобы исторические относительные ссылки не выглядели действующими. Обновлены инструкции, техническое приложение и границы применимости видео/старой регрессии. PDF inspection старого alias также сохранён: он относился к прежнему промежуточному экспорту, поэтому новый результат привязан к текущему PDF отдельно.
- Финальный этап: отдельный каталог `dist/Материалы-2026-11-17`, сборка по существующему allowlist, свежая распаковка, новая среда и установка трёх packages без сети, pip check, регрессия, загрузки, PDF и ссылки всей поставки. Результаты этой стадии находятся снаружи архива в «Проверки», чтобы не возникало самохеширования. Прежний комплект сохранён целиком.
