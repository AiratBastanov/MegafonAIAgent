# Варианты — demo-002, версия 2

Учебный выбор, `awaiting_decision`. Критерии: соответствие текущей функции задаче, возможность проверить дополнительную ценность, избегаемая экономика и обратимость. Весовые баллы и предопределённый победитель не используются.

| Вариант | Механизм и компромисс | Сильное возражение | Когда предпочтителен |
|---|---|---|---|
| **Оставить как есть** | Сохранить внутренний прототип передачи файлов без коммерческого запуска и новых функций; оплачивать только действительно нужное поддержание. Потенциальная внешняя выручка откладывается. | Внутренняя польза и стоимость поддержки не измерены; ожидание само по себе не даёт знания. | Внутренняя польза превышает поддержание, а ценность/стоимость дополнительного исследования пока не обоснована. Задать дату пересмотра после оценки фактических расходов. |
| **Проверить исходящее предложение для небольших агентств** | Нынешняя передача плюс предлагаемая ручная помощь в подготовке комплекта. Меньше разработки, быстрее проверяется процесс; помощь может быть дорогой. | Dropbox уже закрывает базовую передачу. Две оплаты из восьми синтетических проб не доказывают спрос; ручное сопровождение может не окупиться. | Есть согласованный небольшой бюджет обучения, прототип проходит приёмку, организации реально испытывают проблему координации и согласны участвовать. После проверки есть дополнительная польза и приемлемые реальные затраты. |
| **Разработать входящий сбор для бухбюро** | Другой сценарий: клиент загружает документы в запрос организации. Нужны новая функция и отдельная проверка доступа/обработки данных; сегодняшняя ссылка на скачивание задачу не решает. | Восемь «пилотов» — интерес, не восемь оплат. Публичные file requests уже существуют. Стоимость разработки и требований неизвестна. | Подтверждена существенная неудовлетворённая задача относительно доступной альтернативы, есть платёжное подтверждение и обоснованная стоимость решения. До этого возможна только проверка задачи/прототипа. |
| **Закрыть самостоятельное направление** | Прекратить коммерческую инициативу, не разрабатывать новые возможности; спланировать выгрузку/удаление тестовых материалов и обязательств. Исторические затраты не возвращаются. | Можно потерять полезную узкую задачу; неизвестны обязательства, стоимость выхода и внутренняя польза. | Подтверждено отсутствие оплачиваемой дополнительной ценности либо перспективы положительного избегаемого вклада; расходы выхода сопоставлены с дальнейшим поддержанием, владелец утвердил закрытие. |

Предложение C011: до решения сохранять текущий внутренний режим; если владелец выделяет ресурс на получение знания, провести ограниченную проверку исходящего предложения агентствам. Это не коммерческий запуск. Разработку входящего сбора отложить; keep и close остаются реальными альтернативами при неблагоприятных результатах. [C001/C004/C005/C006/C007/C008/C010]

Цена возможности существенна: ручная помощь расходует ресурс, который мог бы обслуживать другой продукт. Её фактическую стоимость нужно сравнить с ценностью информации до пилота; исходные материалы этой оценки не дают. Решение о расходах остаётся у владельца.
