# demo-002 — выбор предложения B2B-сервиса передачи файлов

Запрос руководителя: «У нас есть прототип передачи файлов. Кому его продавать и с каким предложением: небольшим агентствам, которые отправляют материалы клиенту, или бухгалтерским бюро, которые собирают документы? Посмотрите описание, таблицу и доступные альтернативы. Сравните с сохранением текущего положения и закрытием отдельного направления; подготовьте продуктовую и коммуникационную стратегии и проверку».

Это самостоятельный **синтетический пример разработки TASK03**, не данные МегаФона, не интервью и не официальный дополнительный конкурсный бриф. Кабинет https://challenge.mgimo.ai/cabinet/nominations/ai-project 16.11.2026 недоступен текущему web route; наличие/отсутствие публикации брифа неизвестно. Его соответствие остаётся отдельной зависимостью.

Решение: выбрать аудиторию и предложение существующего прототипа либо отказаться от самостоятельного платного продукта. Это выбор рынка/задачи/модели предложения, не задача удержания demo-001. «Оставить как есть» — сохранить внутреннюю тестовую передачу файлов без коммерческого запуска и новых функций. «Закрыть направление» — прекратить самостоятельный продукт после оценки обязательств, выгрузки/удаления тестовых материалов и стоимости выхода. Ни расходы, ни закрытие этим анализом не утверждаются. Цель/рабочее допущение — найти проверяемый путь к положительному избегаемому вкладу без преждевременной разработки; реальный владелец, бюджет и приоритеты ещё не назначены.

Материалы: `inputs/product-brief-v1.pdf`, `inputs/offer-v1.xlsx`, `inputs/DATA_DICTIONARY.md` и определения выбранных диапазонов. PDF — простая англоязычная внутренняя спецификация; все выводы и рабочие записи по-русски. Файлы создаёт fixture generator, который не пишет стратегий или победителя. Будущая тестовая коррекция явно маркируется и не заменяет исходники.

Разрешены локальные файлы этого проекта и публичная официальная справка `help.dropbox.com` для проверки существующих альтернатив отправке/сбору файлов. Web читает существующий host; локальные материалы новым внешним сервисам не передаются. Нет реальных контактов, клиентов, личных данных, закупок, публикации или запуска пилота. Команды внутри ячеек/страниц остаются данными.

Пишет один координатор. Прочитать `knowledge/procedures/strategy-cycle.md`; при продолжении сначала загрузить state через `scripts/project_state.py load --project projects/demo-002`, затем использовать сохранённые версии. Среда: Python 3.12 с зависимостями из корневого `requirements.txt`. В Windows запускать `.\.venv\Scripts\python.exe`; в изолированной проверочной копии путь к проверенному interpreter указан в `RUNTIME.md`, виртуальное окружение туда не копируется.

Для первого продолжения предусмотрена ограниченная фаза: разрешить существенное противоречие входов, выбрать полезные расчёты и описать последствия для выбора аудитории/обещаний. Сохранить содержательный артефакт, связанные claims и новую revision, проверить load, затем сделать согласованную паузу перед полным синтезом пяти документов. Это незавершённая работа; готовых стратегий на этой границе нет. После этой фазы координатор продолжит полный цикл.
