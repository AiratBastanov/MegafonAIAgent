# Наблюдаемые ресурсы

Предыдущие измерения сохранены в [сводке ресурсов проверенного продолжения](../provenance-release/RESOURCES.md). Они не суммируются повторно и не превращаются в оценку цены.

В этой задаче выполнен один ограниченный анализ UCI текущим координатором. Проверка структуры, импорт, подготовка индикаторов и два арифметических пути заняли 1,100481 секунды внутри измеряемого Python-процесса; это не время всей задачи и не скорость работы человека. [Первичное измерение](projects/uci-shoppers/evidence/calculations/independent-v1.json).

Нового отдельного LLM-продолжения не было: исполняемый код и постоянные инструкции не менялись. Число токенов текущей беседы, фактические денежные списания, активное время человека и полное время подготовки неизвестны. Никакая из этих величин не приравнивается к нулю.

Времена упаковки, установки без сети, проверок и сетевой публикации сохраняются в соответствующих протоколах исполнения. Длительность исторического видео — 451,9 секунды монтажа, не время исполнения.

Измеренные интервалы выпускной проверки:

- Создание среды: 4.562 с, код завершения 0.
- Установка без сети: 2.360 с, код завершения 0.
- Проверка зависимостей: 0.484 с, код завершения 0.
- 100 тестов: 27.953 с, код завершения 0.
- Проверка файлов и истории: 10.469 с, код завершения 0.
