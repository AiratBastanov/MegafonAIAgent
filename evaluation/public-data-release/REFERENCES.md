# Предоставленные руководства

Все шесть доступных копий прочитаны с Desktop в этой задаче. Ниже — объяснение применённых принципов, не точные цитаты. Полные внешние тексты не включены в репозиторий. Их доступные владельцу пути и контрольные суммы сохранены в [реестре](references.json).

- **Codex Prompting Guide.txt** — Доводить поручение до проверенного результата; применять точные инструменты и адресные проверки.
- **Model guidance _ OpenAI API.txt** — Сохранять исходную задачу при уточнениях; явного разрешения пользователя достаточно; не расширять проверки без причины.
- **Rethinking skills and prompts for GPT-6 Astra _ OpenAI Developers.txt** — Не наращивать инструкции и каркас без пользы; читать документацию по задаче.
- **PromptGuide.txt** — Ясные цель, контекст, результат и границы; материал должен быть пригоден для адресата.
- **AgentsMD.txt** — Обязательные правила находятся в AGENTS.md; вложенные инструкции имеют свою область.
- **PersonalizeChatGpt.txt** — Предпочтения стиля отделены от обязательных инструкций и памяти задачи.

Конкретное поручение пользователя имеет приоритет: commit и push разрешены; архитектура и проверенные инструкции не переписываются.
