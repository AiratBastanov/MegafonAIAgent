# План проверки — версия 1

Предложение, эксперимент не проводился, люди не приглашались. Исходные данные и плановые параметры синтетические; реальные расходы и решение владельца ещё нужны.

**Гипотеза:** ручной направляемый первый сценарий повышает D28 у новых recurring относительно текущего продукта; оплата и вклад оцениваются отдельно. Ни сегментные 60%, ни мнение менеджера не устанавливают причинность. [C003/C006]

**Сравнение:** новые recurring случайно распределяются 1:1 при регистрации, до воздействия, в контроль (текущий путь) и тест (тот же продукт плюс направляемый сценарий). Набирать одновременно, фиксировать канал и самоописанный сегмент до назначения. Анализ intention-to-treat всех назначенных; не исключать тех, кто не активировался. Ручной контакт одинаковой длительности в контроле с нейтральной информацией, иначе оценивается весь пакет «сценарий+внимание», а не отдельный экран.

**Метрики:** D28 = уникальные назначенные пользователи с ≥1 выполнением задачи на днях22–28 / все назначенные с завершившимся 28-дневным окном. Активация = создали первую задачу в24ч / все назначенные. Оплата = оплатили первый месяц / все назначенные; выручка, возвраты и переменные расходы за один первый месяц. Минуты ручной помощи × фактическая ставка входят в дополнительные затраты. Пропавшая телеметрия — не нулевое удержание: при систематической потере результат недостоверен. [S001@1 body/b5/p4; ECON-v1 assumptions]

**Период/объём:** сначала 4 недели набора и ещё28 дней дозревания последнего пользователя. При условном повторении сентябрьского потока100 recurring/месяц это около50 на группу: лишь проверка осуществимости и крупного вреда, недостаточно для уверенного вывода об эффекте10 п.п. Для более точной оценки предложены400 на группу: около8 месяцев набора при том же неподтверждённом потоке +28 дней. Нормальное приближение при доле около60% даёт погрешность разницы порядка7 п.п.; это плановый ориентир, не гарантия мощности. До запуска согласовать нужный минимальный эффект/объём и не подгонять их по результатам. Дедлайн конкурса не меняет горизонт рыночного исхода. [CALC-segments-v1 denominator; плановые допущения]

**Пороги предложены для согласования:** практическая цель +10 п.п. D28; для продолжения инвестиций нужен положительный нижний95% интервал разницы, точечный эффект≥10 п.п. и положительный дополнительный вклад по фактическим затратам. До старта фиксируется метод интервала разницы двух долей, например Newcombe/Wilson. Сценарные9 дополнительных оплат на100 из ECON-v1 — лишь иллюстрация экономического порога, не универсальное условие. Неуспех: верхняя граница интервала ниже10 п.п. при достаточных данных либо подтверждён отрицательный дополнительный вклад. Пограничный/широкий интервал, несозревшие окна и неверная телеметрия → «неопределённо», не масштабировать.

**Вред:** жалобы на навязчивую помощь, лишние задачи/уведомления, возвраты, рост нагрузки поддержки. Остановить воздействие при подтверждённом ущербе/утрате данных; предложенный количественный предохранитель — рост доли жалоб≥5 п.п. относительно контроля после минимум50 наблюдений в группе, с разбором каждого серьёзного случая сразу. Не считать отсутствие жалоб в малой выборке доказательством безопасности. Интервью/контакты только с согласием, без персональных данных в репозитории.

**Развилка:** при пользе и экономике — оценить автоматизацию сценария; при отсутствии эффекта — проверить задачу/ценность сегмента и сравнить keep/close; при спросе именно на автоповтор — отдельный прототип против существующей альтернативы. Закрытие/расходы утверждает руководитель, автоматического решения нет.
