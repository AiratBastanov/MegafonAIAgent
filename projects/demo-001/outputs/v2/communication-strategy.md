# Коммуникационная стратегия — актуальная версия 2

Учебный синтетический пример, предложение. Публикаций/контактов не было. Коммуникация соответствует последовательности «сверка данных → условный тест на текущем продукте»; до этого массовые кампании не предлагаются. [C012]

| Элемент | Предложение и основание |
|---|---|
| Аудитория/ситуация | Новый пользователь сам выбрал регулярные дела и хочет сформулировать конкретную задачу. Сегмент исследования, не доказанный рынок. C010/C011. |
| Барьер | Возможное непонимание первого полезного действия, несоответствие ожиданий или качество привлечения. Причина не установлена; после коррекции нельзя сводить всё к составу регистраций. C011. |
| Сообщение | «Запишите одно регулярное дело, задайте дату и отметьте выполнение. Следующую задачу пока можно скопировать вручную». Только нынешние возможности. C001. |
| Поддержка | Показ пути на конкретной версии продукта и результат выполнения, если реальный интерфейс подтвердит сценарий. Без процентов экономии/обещаний роста продуктивности. C001. |
| Экран продукта | Объяснить первое действие в тестовом варианте; изменение текста/сценария пока предлагается, не внедрено. |
| Приглашение в пилот | После решения владельца объяснить добровольное участие и ручную помощь. Контроль получает обычный продукт; оценивается весь пакет помощи, это не чистый тест текста. |
| Справка/поддержка | Объяснить ручное копирование и отсутствие автоповтора; отвечать на наблюдаемые затруднения. C001. |

Автоповтор — только рассматриваемая будущая возможность, без обещания срока или доступности. Заявлять функциональную уникальность нельзя: публичная справка Todoist уже описывает повторяющиеся даты. [C004] Роли каналов — рекомендации, не разрешение на рассылку/рекламу и не измеренная эффективность. Если выбран иной продуктовый вариант, обновить сообщение до публикации.
