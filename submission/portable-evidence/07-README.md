Для нового продукта: «Начни анализ проекта product-002: выбираем направление сервиса; материалы в projects/product-002/inputs». Дайте разрешённые материалы и объясните решение. Для продолжения после закрытия чата откройте **новый чат в этой папке** и используйте запрос выше.

## Подготовка

Проверенная среда: Windows, PowerShell 5.1, Python 3.12.10, Codex CLI 0.169.0-alpha.11.1. Нужна действующая авторизация существующего Codex, локальное выполнение Python и доступный web/open для актуальных сайтов. Новые API-ключи и платные провайдеры не нужны. Цена существующего доступа неизвестна; это не утверждение о нулевой стоимости.

В PowerShell из корня:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Зависимостей вне стандартной библиотеки нет; установка pip не требуется. Глобальные пакеты/настройки не меняются. Папка работает без Git checkout; intended remote — https://github.com/AiratBastanov/MegafonAIAgent. Публикация не выполнена.

Инструкции: [AGENTS.md](../../evaluation/continuation-workspace/AGENTS.md), процедуры [strategy-cycle](../../evaluation/continuation-workspace/knowledge/procedures/strategy-cycle.md) и [evidence-review](../../evaluation/continuation-workspace/knowledge/procedures/evidence-review.md). Текущий managed profile запрещает запись в `.agents`, поэтому используются обычные процедуры с явной навигацией. Автообнаружение repository-local skills не заявляется. Возможность их штатной установки можно проверить в другом разрешённом профиле, без обхода защиты.

## Форматы и сохранение

Поддерживаются простой DOCX (абзацы/таблицы в порядке документа), CSV UTF-8, TXT/Markdown и ограниченная выдержка реально прочитанной страницы. DOCX не получает вымышленных номеров страниц; сложные вложения, merged/nested tables, tracked changes, рисунки и колонтитулы отклоняются. PDF/XLSX/OCR и внешние записи отложены. Не передавайте секреты и персональные данные.

Safeguards по умолчанию: 20 MiB на файл, 80 MiB распакованный DOCX, 50 000 CSV строк, configurable через CLI. Это технические ограничения ввода, не лимиты числа источников, времени исследования или размера обязательной демонстрации. Подробности: [инструменты](../../evaluation/continuation-workspace/knowledge/tool-contracts.md), [записи](../../evaluation/continuation-workspace/knowledge/record-contracts.md).

Один координатор пишет проект. `state/current.json` содержит цель, выполненное, evidence/claims, вопросы, pending и next_action; `previous.json` и history сохраняют прошлое. Входы/артефакты привязаны хешами. Не редактируйте использованные версии; добавляйте новые. Повреждение обнаруживается и показывается, предыдущий вариант восстанавливается явно. Несколько одновременных писателей не поддерживаются. Кооперативный стоп не гарантирует сохранение при аварийной отмене UI.
