## Первый запуск из архива: Windows / PowerShell

Нужны Windows, PowerShell, Python 3.12 в PATH и уже авторизованный Codex с разрешением читать и записывать эту папку и запускать Python. Три закреплённых wheel включены в `third_party/wheels`: установка ниже не требует сети или старой `.venv`. Происхождение и SHA указаны там же. Для текущих интернет-источников нужен web-инструмент хоста. Подписка/доступ Codex предоставляются владельцем; цена, квота и расход токенов здесь неизвестны. DeepSeek/API-ключ для этих утилит не требуется.

Сохраните ZIP, откройте PowerShell в папке с ним. Имя новой папки должно ещё не существовать:

```powershell
Expand-Archive -LiteralPath .\MegafonAIAgent-TASK06-rc1.zip -DestinationPath .\MegafonAIAgent-rc1
Set-Location .\MegafonAIAgent-rc1
python --version
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --no-index --find-links third_party/wheels -r requirements.txt
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -X utf8 scripts/project_state.py load --project projects/task06-rehearsal
```

Activation.ps1 не нужен: команды используют Python из новой `.venv`. Не копируйте старую `.venv`. Текст в PowerShell читайте `Get-Content -Encoding UTF8`. Если установка или host отклоняет операцию, сохраните диагноз; не отключайте ограничения. Успех unittest и load подтверждает Python-часть, а независимое продолжение LLM проверяется отдельно.

Откройте распакованную папку как рабочую папку существующего Codex. Для нового анализа создайте новый ID и положите разрешённые материалы в `projects/<id>/inputs`. Например: «Начни анализ проекта my-product: материалы в projects/my-product/inputs. Помоги выбрать аудиторию и предложение; нужны продуктовая и коммуникационная стратегии и план проверки». Существующие демонстрационные проекты уже имеют историю; не импортируйте их заново.

Обычные запросы: «Что сейчас готово и что требует моего решения по проекту my-product?», «Остановись и сохрани место продолжения», «В новой версии таблицы изменились затраты; пересчитай затронутые выводы, сохрани старые». Для продолжения откройте новый чат в той же папке: «Продолжи анализ проекта my-product по сохранённому состоянию». Кооперативная остановка сохраняет ближайшую безопасную границу; аварийное закрытие UI такого результата не гарантирует.

Ниже — подробности существующего workflow и исторических проверок. Текущие статусы TASK06 находятся на странице жюри.

Откройте эту папку в Codex с доступом к локальным файлам и напишите один запрос:

> Проанализируй проект demo-001 по материалам в inputs. Подготовь продуктовую и коммуникационную стратегии и план проверки.

Для уже сохранённого проекта:

> Продолжи анализ проекта demo-001 по сохранённому состоянию.

Агент сам читает инструкции, проверяет сохранённые результаты, вызывает утилиты и ведёт работу. Для нового продукта: «Начни анализ проекта product-002: выбираем направление сервиса; материалы в projects/product-002/inputs». Дайте разрешённые материалы и объясните решение. Не нужно вручную запускать каждый этап Python.

После выбора можно написать: «Мы выбрали этот вариант. Зафиксируй основания, обязательства и условия пересмотра», «Что сейчас требует моего решения по проекту?» или «Что просрочено, что заблокировано и какие основания нужно перепроверить?». Агент сохраняет инструкцию и исходные версии, показывает обязательства и проверяет влияние новых материалов. Неизвестные сроки/владельцы остаются неизвестными. Новое предложение не заменяет принятый выбор. Проверки идут **при вызове**, без фонового мониторинга и отправленных напоминаний.

«Остановись и сохрани место продолжения» создаёт checkpoint на ближайшей безопасной границе. «Исправь: в новой версии таблицы изменилось удержание; пересчитай затронутые выводы» сохраняет предыдущий результат и создаёт новую версию. Для продолжения после закрытия чата откройте **новый чат в этой папке** и используйте запрос выше.

## Форматы и сохранение

Числовая граница CSV: до 18 цифр коэффициента и модуль десятичного exponent ≤12; превышение явно отклоняется.

Поддерживаются простой DOCX, CSV UTF-8, TXT/Markdown, выдержка реально прочитанной страницы, выбранные XLSX-диапазоны и простой текстовый PDF. DOCX не получает вымышленных номеров страниц; сложные элементы отклоняются. XLSX сохраняет листы/ячейки/типы, hidden/merged, формулы отдельно от кэша; вычисление идёт из literal cells с явными единицами/периодом. PDF сохраняет физические страницы и фрагменты текста; сканы/шифрование/неподдерживаемые конструкции дают понятный отказ, неоднозначная вёрстка требует проверки. OCR, визуальная приёмка и произвольные таблицы PDF не заявляются. Не передавайте секреты и персональные данные.

Safeguards по умолчанию: 20 MiB/файл, 80 MiB распакованный OOXML, 50 000 CSV строк, 100 000 XLSX ячеек, 64 листа; PDF 200 страниц, 8 MiB decoded stream/страницу, 2 млн символов. Пределы настраиваются CLI и не являются квотой исследования или абсолютной гарантией памяти для враждебных PDF. Подробности/пример selection и XLSX spec: [инструменты](../../knowledge/tool-contracts.md), [записи](../../knowledge/record-contracts.md).

Один координатор пишет проект. `state/current.json` содержит цель, выполненное, evidence/claims, вопросы, pending и next_action; `previous.json` и history сохраняют прошлое. Входы/артефакты привязаны хешами. Не редактируйте использованные версии; добавляйте новые. Повреждение обнаруживается и показывается, предыдущий вариант восстанавливается явно. Несколько одновременных писателей не поддерживаются. Кооперативный стоп не гарантирует сохранение при аварийной отмене UI.
