# Публикация и доступ жюри

Владелец **разрешил commit и push** проверенного проекта в [AiratBastanov/MegafonAIAgent](https://github.com/AiratBastanov/MegafonAIAgent). Повторное разрешение не требуется. Старые документы с ожиданием разрешения сохранены как история.

## Точный адрес и состав

Целевая ветка — **main**. [Читательский вход для жюри](https://github.com/AiratBastanov/MegafonAIAgent/blob/main/submission/README.md); [описание](https://github.com/AiratBastanov/MegafonAIAgent/blob/main/submission/PROJECT_DESCRIPTION.md). Репозиторий читается непосредственно на GitHub; локальный HTML не нужен.

На момент подготовки авторизованный API подтвердил владельца, пустой репозиторий, приватность и право записи. [Протокол](../evaluation/public-data-release/remote-before.json). Правила ветки и наборы правил вернули 403: функция требует другого тарифа либо публичного репозитория. Их настройки не меняются; применяется обычный push без force.

Новый переносимый комплект: dist/Материалы-2026-11-17-3/. В нём «Начать.html», PDF, неизменное видео, «Проект.zip», распакованная папка «Проект», реестры и результаты проверок. Предыдущие три комплекта сохранены.

В Git передаются выбранные файлы проекта: код, инструкции, методы, примеры с историей, атрибуция UCI, материалы жюри, проверочные свидетельства и закреплённые Python-зависимости. Полный рабочий Desktop, временные среды, настройки авторизации, исходный ZIP владельца и большие дистрибутивные ZIP не передаются.

Состав закрепляется реестром и проверяется перед commit: имена и размер каждого файла, отсутствие секретов известных форматов, исходники, зависимости и ссылки. [Официальные ограничения GitHub](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github): предупреждение после 50 MiB, запрет обычного Git для файлов больше 100 MiB. Дистрибутивные ZIP остаются локально; вложения отдельного GitHub Release этой задачей не создаются.

## Доступ

**Репозиторий закрыт.** При анонимной проверке — 404, при авторизованной — 200. Push не меняет видимость и не даёт жюри доступ автоматически. Владелец должен отдельно предоставить членам жюри доступ к репозиторию либо отдельно решить вопрос публичности. История закрытого репозитория не раскрывается без такого решения.

После push проверяются точный commit в main, чтение обязательных файлов через авторизованный GitHub и повторный анонимный доступ. Итоговый протокол сохраняется рядом с комплектом в «Проверки/remote-after.json», а адрес commit — в «Публикация.md». Это внешняя квитанция о доставке; она не включается в самохеширование архива.

## Что остаётся для конкурсной подачи

1. Предоставить жюри фактический доступ и проверить чтение вне сессии владельца.
2. Отдельно загрузить неизменное видео на разрешённую площадку и проверить воспроизведение без входа. [Текст кейса](../DescriptionMegafonAIAgent.txt) перечисляет Яндекс Диск, Google Диск, VK Видео, RuTube и YouTube; адрес не придумывается.
3. Через доступную авторизованную сессию прочитать [дополнительный бриф и форму](https://challenge.mgimo.ai/cabinet/nominations/ai-project), сверить требования и затем отдельно отправить заявку капитаном.

Дополнительный бриф не прочитан: веб-доступ не сработал, подключённых документных сессий нет. Искать или переписывать его владельцу не предлагается. Известен только предоставленный основной текст кейса; учебный пример не объявляется одобренной заменой дополнительного задания.

Готовые сведения: название — «Стратег Фабрики продуктов»; результат — проверяемые основания, разные варианты, согласованные стратегии и сохранение после паузы. Ограничения — учебный основной пример, отсутствие рыночного пилота и недоказанное превосходство над обычным чатом. Новая проверка UCI подтверждает работу на независимом CSV в указанном объёме.

Загрузка видео, изменение доступа, сообщения организаторам и отправка формы остаются отдельными действиями. Разрешение на commit и push уже действует.
